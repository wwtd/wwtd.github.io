加速的2026年

发表于 2026-11-04 更新于 2026-11-04

我听说过一个说法，人小的时候觉得时间过得特别慢，长大后觉得时间过得特别快，这是因为小的时候老是会有很多没见过的新鲜事，大脑没有时间刻度但是有新鲜的事情就会记录下来。长大了，每天日复一日，场景不断重复，大脑就忽视了这些，当做噪音过滤掉了。

我现在发现2026年过的好漫长，这种变化好像是AI带来的。
作为一个底层程序员，大模型深刻的改变了我的生活。它带来的加速度甚至让我觉得自己在飙车，有非常强烈的推背感。

一个模糊的AI浪潮时间线：

  • 最开始的chatgpt一夜爆火，各种类似的chat box如火如荼。
  • baidu好像还搞了一会儿文心一言，有的时候不方便访问墙外的还会用它顶上（我还推荐了一个非程序员的朋友用文心一言学会了python）。
  • 然后就是MCP、Skill、Agent、harness。概念一个接一个。
  • 公司开始采购了ali推的lingma。你倒不能说它不能用，但是说不上好用罢了，大部分时候还是用它耽误我思路的程度。先锋一点的同事已经在玩各种agent了，claude code、opencode，中间好像还风靡过一阵子openclaw，把mac mini都搞断货了。
  • 之后公司并行采购copilot，大概对应国模glm4.7的时间线。这个时候国模平台的coding plan大战开打，字节的火山方舟、glm coding plan、ali百炼、硅基流动等等，那个时候国模的可用性还没有达到现在的甜点区，各个平台都在补贴冲日活，我也辗转了几个平台分别品鉴了他们的首月优惠。那个时候，我对它们的理解还是，已经可以产出可用的产物了、但是较大规模的工程还搞不定、AI好像更擅长前端……
  • 后面就是各大厂商冲日活算了半天亏太多，各大coding plan回归token plan（我记得xiaomi刚发他们的token plan的时候被骂成狗，人家都是按对话次数，你是按token，雷总玩不起hh）。
  • 后来部门开始逐渐内部部署了deepseek v4 flash、4.1 flash与glm4.7、5.2、5.3，token无限量供应，内部模型不限制代码仓库密级。大概从这个阶段开始，飞轮就越转越快了。
  • 部门内部推动AI渗透率，token使用量越多越好；喊出一人一个skill的口号；内部飞书文档、jira、gitlab、各种内部系统陆续打通。

我们真的好像进入到一个人均超人的时代，代码先天带有丰富的上下文、jira票和飞书文档是天然的过程资产，加上无限的token，我甚至在没有任何上下文的情况下接手了一部分离职同事的需求，没有任何压力。
我目前coding基本上就是pi/omp，想要插件就手搓一个自己用。在公司敲代码就用公司提供的token，自己在家就用类似opencode go、command code goat之类的开源模型聚合plan，10刀的已经足够大部分使用。

我觉得2026年发生了很多值得记忆的事情，甚至觉得上半年和下半年完全都不一样。这样算不算AI延缓了我的衰老，赠予了我一些时间呢？

AI带来革新和进步的同时，快速的变化也在摧毁着人们的稳定预期。现在我甚至无法做出长期的规划，每次想到这些，脑子就会告诉我：嘿，蠢蛋，你怎么敢假定以后的这些前提条件还存在呢。

是呢，蠢蛋们。真实的选择只能是：关注好自己的身体，不要轻易负债，享受AI赠予我们的时间吧。
